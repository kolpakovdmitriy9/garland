Гирлянда-конструктор

Мигающие огоньки через всю ширину страницы. Нажмите на гирлянду — режим мигания сменится, как на настоящей ёлочной гирлянде.

Настройки

Управление применяется ко всем гирляндам на странице (через JS API компонента).

Режим мигания
Цвета лампочек

Гирлянда внутри блока

Вторая гирлянда живёт в потоке страницы — скроллится вместе с блоком и отзывается на те же настройки.

Как подключить

На любую страницу любого сайта: разметка, два файла и готово. Файлы можно скачать из репозитория или подключить напрямую по ссылке CDN — тогда обновления применятся сами.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/kolpakovdmitriy9/garland@main/assets/css/garland.css"/> <div class="garland" data-pin="top" data-colors="multi" data-mode="twinkle"></div> <script src="https://cdn.jsdelivr.net/gh/kolpakovdmitriy9/garland@main/assets/js/garland.js"></script>

Локально вместо CDN-ссылок используйте assets/css/garland.css и assets/js/garland.js — это весь компонент. Стили самой этой демо-страницы лежат отдельно, в assets/css/garland-demo.css, и для переноса на другой сайт не нужны. @main в адресе — ветка: всегда последняя версия; чтобы зафиксировать, укажите хэш коммита.

data-pin — закрепление: top / bottom / без атрибута для гирлянды в потоке. data-colors — multi (все разные) / two (два цвета) / one (один цвет). data-mode — стартовый режим: on, wave, twinkle, chase, off. Клик по гирлянде переключает режимы по кругу.

JS API на элементе: el.garland.setMode('wave'), el.garland.setColors('two', '#ff3b30', '#0a84ff'), el.garland.next(), el.garland.getState().
